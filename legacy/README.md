# Legacy site (archived)

This folder is the **original Otodrive website** that was live at `https://www.otodriveafrica.com/` when the project was baselined on 27 October 2026.

It is kept for reference only and is **not** part of the current site. The redesigned site lives in the repository root.

Note: this archive is not meant to be browsed directly — its styles, scripts and images were shared with the old root layout, so relative links will not resolve here. The fully working history is preserved in Git (the baseline commit).
